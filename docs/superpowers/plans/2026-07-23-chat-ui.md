# Chat Widget UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A global floating draggable/resizable chat widget with streaming text
chat + push-to-talk voice, on top of the existing `/api/chat` backend.

**Architecture:** An always-mounted overlay in `__root.tsx` toggles a bubble ↔ a
`motion.div` window (geometry hook drives position/size). `useChat` streams from
`POST /api/chat` (capturing `x-chat-id`); a new `POST /api/chat/transcribe`
turns recorded audio into text for voice input.

**Tech Stack:** `@ai-sdk/react` `useChat`, `ai@6` `DefaultChatTransport`, motion,
jotai, `use-stick-to-bottom`, `react-markdown`+`remark-gfm`, better-auth
(`authClient.useSession`), Gemini via AI Gateway.

Spec: `docs/superpowers/specs/2026-07-23-chat-ui-design.md`. Reference impl to
port from: `/Users/rahul/Developer/3d-airmanship/projects/airmanship-web/src/components/chat-widget/`
and `.../src/app/api/chat/transcribe/route.ts`.

## Global Constraints

- **Presentational components are hookless** pure functions (repo rule + render
  test constraint: react-compiler nulls the hook dispatcher → hook-using
  components are NOT render-tested). Ported logic hooks are tested via
  `renderHook`; ported pure helpers via plain vitest.
- **Base UI first** for standard controls; the draggable window is a justified
  custom component (document why in a comment).
- **Logical CSS + theme tokens only:** `inset-inline`, `ms-`/`me-`,
  `--color-accent-9`/gray scale, `cn` from `#/lib/cn`. NEVER the old repo's
  `bg-interactive-*`/`surface-page`/`border-primary` tokens or hardcoded colors.
- **Files:** kebab-case names, PascalCase components; `src/components/**`,
  `src/atoms/**`, `src/routes/**` use SINGLE quotes + `#/` alias; `src/db|server`
  use double quotes + `@/`. Tests import via `#/`.
- **Transcription model:** the shared `geminiFlash` const from `#/ai/ai-provider`
  (`google/gemini-3.6-flash`), via the gateway.
- **Transcribe route** self-gates: `await auth.api.getSession({ headers })` → 401.
- **`x-chat-id`:** the widget reads it from the `/api/chat` response and echoes it
  as `chatId` on the next turn (one `aiChats` row per session).
- **Commit trailers** end every message with:
  `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`
  `Claude-Session: https://claude.ai/code/session_0136Ar3nkk6zkL8i3DbYCmaJ`
  Explicit `git add` paths only; never stage `src/env.ts`, `src/styles.css`,
  `src/utils/brand-colors.*`, `scripts/generate-theme-css.*`.
- **No history UI** in this plan; **no geolocation round-trip** (drop that branch).
